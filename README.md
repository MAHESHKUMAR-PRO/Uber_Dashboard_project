# 🚗 Uber Analytics Dashboard | Power BI

## 📌 Overview

This project is an **Uber Analytics Dashboard** built using **Microsoft Power BI** to analyze ride booking data and understand important business insights.

The dashboard helps analyze **total bookings, revenue, trip distance, payment methods, vehicle types, and ride trends**. Interactive filters and visualizations allow users to explore the data and identify useful patterns.

## 🎯 Project Objectives

* Analyze overall Uber ride performance
* Understand booking and revenue trends
* Analyze customer payment preferences
* Compare different vehicle types
* Identify popular pickup and drop-off locations
* Analyze trip distance and booking patterns
* Create an interactive and user-friendly Power BI dashboard

## 📊 Key KPIs

The dashboard provides important Key Performance Indicators (KPIs), including:

* **Total Bookings**
* **Total Revenue**
* **Total Trip Distance**
* **Average Trip Distance**
* **Average Booking Value**
* **Total Ride Count**

## 📈 Dashboard Analysis

### 1. Overall Performance

The dashboard provides a high-level overview of Uber's performance using KPIs such as:

* Total bookings
* Revenue
* Trip distance
* Average booking value
* Average trip distance

### 2. Booking Analysis

The project analyzes:

* Number of bookings
* Booking trends
* Ride distribution
* Booking patterns over time

### 3. Vehicle Analysis

Different vehicle categories are compared based on:

* Number of bookings
* Revenue
* Trip distance
* Overall performance

### 4. Payment Analysis

The dashboard provides insights into different payment methods and helps understand customer payment preferences.

### 5. Location Analysis

Pickup and drop-off locations are analyzed to identify frequently used locations and ride patterns.

### 6. Time-Based Analysis

Ride data is analyzed based on different time dimensions to understand when booking activity is higher or lower.
